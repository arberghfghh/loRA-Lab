Getting started

  2. Tick the LoRAs you want to compare (or none).

  4. Press Generate (or Ctrl+Enter). Every LoRA gets its own column with the same seed.

ⓘ How it works
TeaCache: skips work on steps that barely change the picture. Safe keeps it almost identical; Faster can soften small details. Works with the er_sde, euler and euler a samplers.
ⓘ How it works
NAG (Anima Normalized Attention Guidance): the Turbo presets run at CFG 1, where the negative prompt is ignored. NAG brings it back. Only used when CFG is 1.5 or lower.
ⓘ How it works
Spectrum: predicts most steps instead of running the full model on each one, so it's faster (its author claims about 1.75×). It replaces Speed up (TeaCache) while on, and it changes the picture slightly. Compare before keeping it.
ⓘ How it works
SageAttention (through KJNodes): the same picture with a faster attention step. In our test on an RTX 3050 it was about 8% faster per picture and looked the same. Turn it off if a picture comes out black or noisy.
ⓘ How it works
Detail Daemon: adds small detail (hair strands, fabric, background) at no extra time. Clearly visible on Illustrious / Pony even at Light; subtle on Anima. Strong can get busy.
